- 1 回目は固定ずれ、2 回目は区間ごとに時間を追う方式。2 回目はどの曲でも悪くなったので、固定ずれに戻した。
- 配布オフボを自分で Opus 128k に通しても、2–8k のコヒーレンスは 0.93 ある。コーデックが原因ではなく、cover の中のオケが配布オフボと違う（キー変更の方法やミックスの違い、時間で変わる処理など）。低域（<250 Hz）だけは 0.54–0.97 で一致する。
- 代わりに、cover から BS-RoFormer（リポジトリ既存の `sdr_12.9755`）で声を分離して正解にした。声の無い区間への漏れは -32〜-52 dB（En -10、Odo -6.5 は不良）。音量は、低域の補正ゲインでマスタリング前のレベルに戻した。

## 注意と判断が要る点

- 正解は分離した声なので、分離による劣化（特に高域の残響の取りこぼし）を含む。12 kHz 以上の落ち込みや、Momose・Zarame の尾がプロより短いのはこのため。Momose と Zarame はハモリやダブルのリバーブが残響に混ざっている可能性もある。
- 当てはめた曲は 4 曲で、メインだけの区間は 10–48 秒しかない。パラメータは「傾向」として扱う。
- 引き算を生かすには、cover と同じオケ（キー変更なしの原本や、MIX 側で使った版）が必要。
