## ユーザー試聴フィードバック＆実曲フォレンジックによる構造的解決の系譜

### 1. 「歯擦音が死んでアタックも消えている」「曲によって埋もれたり浮いたり声質が合わない」（v2 → v3/v4）
- **原因**: 広帯域・過敏なディエッサーが子音アタックごと潰していたこと、単一の静的目标値が曲ごとのオケ密度・声域に対応できていなかったこと、および一部 VST3 パラメータ書き込みが離散トークン不一致でサイレント失敗していたこと。
- **構造的解決**: 厳格な読み戻し検証付き `vst3_adapter.py`、アタック保護型 Spectral De-ess、44 曲＋公式オフボ較正による連続 9-NN 音響ターゲット合成を導入。

### 2. 「ピッチ・タイミング補正が崩壊」「2:15 の静かなパートで距離感がズレる」「ハモリが大きい」「Studio One でプラグイン設定が初期値に戻る」（v4 → v5）
- **原因**: Melodyne 済みテイクへの強制ストレッチ、サブベース残存パートでの広帯域 RMS 誤判定、Mid のみでのハモリ音量計測、Pedalboard の JUCE `<VST3PluginState>` ラッパー未復号。
- **構造的解決**: 非破壊既定化、`350 Hz–7.5 kHz` 競合帯域連続距離感トラッカー、真ステレオ K-LUFS ハモリ制御＋実録ハモリ時の `Nectar 3` 自動ミュート、`extract_steinberg_comp_and_cont()` によるネイティブ Steinberg `.vstpreset` 復号。

### 3. 「全体的に声が浮く」「高域にジリジリしたノイズと耳障りなアタック」「ハモリの芯抜き＋語頭潰し」「EQ 6 バンド不足」（v5 → v6.0）
- **原因**: `Waves MV2` の暗騒音持ち上げ、遅い `VCA` アタック＋過ドライブ、全帯域サチュレーションの 4 kHz 以上歪み、最適化後の二重アンマスキング、高域損失から中低域への勾配リーク。
- **構造的解決**: `MV2` 廃止＋高速 `VCA`＋ユニティ `LA-2A`、`240 Hz–4.0 kHz` 中域限定サチュレーション＋Post-Comp `Soothe2`、最適化前アンマスキング、16 バンド `Persistent Q`＋`z_db.detach()`、メインハモリ（芯抜き＋語頭潰し）とコーラスの独立バス分離。

### 4. 「2mix と `.song` の隠れた再現差」「未知曲『エバ』の未マスタリング極小オフボ（`-36.3 LUFS`）でのフェーダー飽和」「シンコペーションでの倍音テンポ誤検出」（v6.0 → v7.0）
- **原因**:
  1. `VocalSynth 2` 等の局所 FX や Bark 子音シェイパーが 2mix WAV のみに焼かれ、Studio One `.song` にライブ VST3 トラックや細分化クリップゲインが渡っていなかった。また `kHs Dual Delay` のパラメータ文字列に Unicode マイナス `\u2212`・狭空白 `\u202f` が含まれていた。
  2. ニコニ・コモンズ等で配布されるマスタリング前の極小音量オフボ（`エバ`: `-36.3 LUFS` / `-38.4 dB` RMS）に対し、ボーカルだけ `-18 LUFS` に揃えて CMA-ES フェーダー範囲を `[-8, +8] dB` に固定していたため、フェーダー下限に張り付いてボーカルが `+8 dB` 過大になっていた。
  3. 局所テンポ推定が落ちサビや 3 連シンコペーションで `2/3` 倍・`3/2` 倍のメトリック倍音へ飛び、一定 BPM のボカロ曲を可変テンポと誤判定していた。また `"02_Verse_PreChorus"` が `"chorus"` 部分一致でサビ扱いされていた。
- **構造的解決**:
  1. Studio One 書き出し用メイン WAV への Bark シェイパー反映、優先度排他ダッキング＋真正 `.vstpreset` 付き Stage ③ ライブ FX スポットトラック注入、細分化距離イベント出力、Unicode トークン正規化を実装。
  2. 極端な小音量／過大オフボ（`< -20.5 LUFS` または `> -8.8 LUFS`）に対するトゥルーピーク `-1.2 dBFS` 保護付き自動ヘッドルームステージング＋初期 V/I 差に追従する適応フェーダー探索中心を導入し、`エバ` を含む全 4 曲で K-LUFS 誤差 `0.07–0.81 dB`・全監査項目 PASS を達成。
  3. 基準 BPM パルスのオンセット自己相関エネルギー検証によってポリリズム倍音ジャンプを棄却し、`エバ`（`140.0 BPM`）・`シックスフィートアンダー`（`127.5 BPM`）ともに正確な原曲テンポへ安定化させつつ真のテンポ変化曲のみを分割する構造を確立。

## 絶対に再導入してはならないアンチパターン（Do-Not-Regress）

- **MP3 逆相引き算によるリファレンスボーカル抽出**（`BS-RoFormer`＋公式オフボ較正のみ使用）。
- **`Waves MV2` アップワード圧縮のボーカル直挿し**（`UAD LA-2A` ユニティ較正を使用）。
- **遅い 1 段目 `VCA` アタック（`attack=1.75`）＋過ドライブ（`drive=1.0`）**。
- **全帯域サチュレーション／全帯域ディストーション**（`Saturation Knob` は `240 Hz–4.0 kHz`、`Trash 2` も `380 Hz–4.2 kHz` バンド制限を厳守）。
- **最適化後のオフボアンマスキング**（必ず最適化前段に組み込む）。
- **10 帯域以上 EQ の高域損失から中低域への勾配リーク**（`z_db.detach()`・`cur_core_margin.detach()` を維持）。
- **未ステージングの極小オフボに対する固定 `[-8, +8] dB` フェーダー探索**（オフボヘッドルームステージング＋適応フェーダー中心を維持）。
- **Pedalboard 生 `raw_state`（JUCE XML）の Studio One 5 直接埋め込み**（必ず `extract_steinberg_comp_and_cont()` で復号し JUCE リーク `0` を維持）。
- **同一 Python プロセス内での複数曲連続フルレンダリング**（1 曲ずつ独立 CLI プロセスで実行する）。
