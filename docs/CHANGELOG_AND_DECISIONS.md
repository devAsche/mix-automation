## ユーザー試聴フィードバックと構造的解決の系譜

### 1. 「歯擦音が死んでアタックも消えている」「曲によって埋もれたり浮いたり声質が合わない」（v2 → v3/v4）
- **原因**: 広帯域・過敏なディエッサーが子音アタックごと潰していたこと、単一の静的目标値が曲ごとのオケ密度・声域に対応できていなかったこと、および一部 VST3 パラメータ書き込みが離散トークン不一致でサイレント失敗していたこと。
- **構造的解決**: 厳格な読み戻し検証付き `vst3_adapter.py`、アタック保護型 Spectral De-ess、44 曲＋公式オフボ較正による連続 9-NN 音響ターゲット合成を導入。

### 2. 「ピッチ・タイミング補正がところどころ崩壊（早すぎ・遅すぎ・詰まり）」「2:15 の静かなパートで距離感がズレる」「ハモリが大きい・混ざらない」「Studio One でプラグインが刺さっておらず音も全く違う」（v4 → v5）
- **原因**:
  1. すでに Melodyne 補正済みのボーカルをボカロ原曲のグリッドへ強制タイムストレッチしたため、人間グルーヴとリード／ハモリ同期が崩壊。
  2. 静寂パート（2:15）はサブベースが残っていたため広帯域 RMS では「静か」と判定できず、サビと同じ音量・飽和で突入していた。
  3. ハモリ音量を M/S の Mid のみで評価したためステレオ広がりを持つハモリが過大出力され、さらに実録ハモリがある曲に `Nectar 3` 合成ハモリも重複ミックスされていた。
  4. Pedalboard の `raw_state` は JUCE 独自の `<VST3PluginState>` XML＋独自 Base64 形式であり、Studio One 5 が求めるネイティブ Steinberg `Comp`/`Cont` バイナリではなかったため、全プラグイン設定が初期化されていた。
- **構造的解決**:
  1. デフォルトを非破壊（レビューマーカー出力）へ変更し、`--auto-pitch` / `--auto-align` をオプトイン化。
  2. `350 Hz–7.5 kHz` のボーカル競合帯域を監視する連続距離感トラッカーを導入。
  3. 真ステレオ K-LUFS 基準のハモリ制御＋実録ハモリ存在時の `Nectar 3` 自動ミュート化。
  4. `decode_juce_base64()` と `extract_steinberg_comp_and_cont()` を実装し、Studio One 5 のネイティブ `.vstpreset` へ完全復号（JUCE リーク 0 件）。

### 3. 「全体的に声が浮く」「高域にジリジリしたノイズと耳障りなアタックが残る」「ハモリが控えめ（芯抜き＋超高速アタック・超低速リリースの語頭潰しを参考に）」「EQ 6 バンドでは少なすぎる」「VocalSynth 2 を購入した」（v5 → v6.0）
- **原因**:
  1. `Waves MV2` の過剰アップワード圧縮（`low_level=16.17`）が暗騒音と高域フロアを持ち上げ、さらに遅い 1 段目 `VCA`（`attack=1.75`, `drive=1.0`）が子音アタックを逆に強調していた。
  2. 全帯域パラレル `Saturation Knob` が 4 kHz 以上の歯擦音・空気帯域を歪ませて「ジリジリ」ノイズを生成していた。
  3. 14 帯域 Bark アンマスキングを最適化の**後**に掛けていたため、ボーカル実効レベルが二重に持ち上がって声が浮いていた。
  4. `Persistent Q` は 873 パラメータ（最大 24 バンド＋Dynamic/Spectral）を持つにもかかわらず 6 バンド静的 EQ しか使っておらず、また初期 10 バンド化時に高域損失の勾配が中低域へ漏れて声の芯をスクープする副作用が発生した。
  5. メインハモリとコーラスが混在処理され、音量も控えめすぎた。
- **構造的解決**:
  1. `Waves MV2` を廃止し、高速クリーン `Softube VCA`（`attack=0.52–0.72`, `output_drive=0.1`）＋全アーキタイプ統一のユニティ較正 `UAD LA-2A`＋6 帯域 Bark 子音トランジェントソフトシェイパーへ刷新。
  2. パラレルサチュレーションを `240 Hz–4.0 kHz` 中域限定バンドパス（DSP 前後＋Studio One 5 `Persistent Q` 前置）で物理遮断し、後段に 4 帯域較正 `Oeksound Soothe2` を配置。
  3. Bark Mid アンマスキングを最適化**前**へ移動し、双方向 `Wet-Tail` 較正を追加。
  4. `Persistent Q` を 16 バンド（HPF＋10 帯域微分彫刻 EQ＋狭 Q ノッチ 2＋3 帯域 Dynamic/Spectral EQ）へ拡張し、`z_db.detach()` / `cur_core_margin.detach()` で中低域スクープを完全防止。
  5. メインハモリとコーラスを独立バスへ分離し、メインハモリへリードフォルマント連動「芯抜き EQ」＋`0.8 ms / 340 ms` 「語頭潰しコンプ」＋奥行きリバーブ＋`-8.6 dB` 真ステレオ K-LUFS を実装。
  6. 新規ライセンス済み `iZotope VocalSynth 2` を全層（レジストリ・アダプタ・Stage ③/④・Studio One 書き出し）へ統合。

## 絶対に再導入してはならないアンチパターン（Do-Not-Regress）

- **MP3 逆相引き算によるリファレンスボーカル抽出**: 位相ノイズ・リミッター歪みが混入するため完全廃止（`BS-RoFormer`＋公式オフボ較正のみ使用）。
- **`Waves MV2` アップワード圧縮のボーカル直挿し**: 暗騒音と高域ジリつきを増幅するため廃止（`UAD LA-2A` ユニティ較正を使用）。
- **遅い 1 段目 `VCA` アタック（`attack=1.75`）＋過ドライブ（`drive=1.0`）**: 子音アタックを耳障りに強調するため禁止。
- **全帯域サチュレーション**: `4 kHz` 以上を歪ませるため必ず `240 Hz–4.0 kHz` 中域限定バンドパスを通す。
- **最適化後のオフボアンマスキング**: ボーカル浮きの直接原因になるため必ず最適化前段に組み込む。
- **10 帯域以上 EQ の高域損失から中低域への勾配リーク**: `sibilance`/`air_sheen` 損失では必ず `z_db.detach()`・`cur_core_margin.detach()` を維持する。
- **Pedalboard 生 `raw_state`（JUCE XML）の Studio One 5 直接埋め込み**: 必ず `extract_steinberg_comp_and_cont()` でネイティブ Steinberg `Comp`/`Cont` に復号する。
- **同一 Python プロセス内での複数曲連続フルレンダリング**: C++ VST3（`Soothe2`＋`LA-2A`）の長時間連続リセットでまれに無言クラッシュするため、1 曲ずつ独立 CLI プロセスで実行する。
