# 4 段階ロードマップ・進捗・次期 R&D 方針 (`v6.0` 時点)

## 1. ユーザーの当初目標（原文保存）

> 私は歌ってみたの活動をしており、高頻度で歌ってみたを投稿するために、MIX の効率化を図っています。私が MIX 自動化のシステムを進めている上で、いくつか目標の段階があります。
>
> **①** オケと声との混ざり具合（主にコンプや EQ の設定によって生み出される距離感や張り付き具合、位置の安定感など）の合格点の設定を、このシステムでつかんで、数値通りに Studio One で設定することで依頼あたりの作業時間や自己制作時間を大幅に削減し、効率を上げる。ある程度どの楽曲でも対応できるように、複数曲でこのシステムを適用しても、私が納得する音の混ざり具合に限りなく近くなっている必要がある。パート間でオケの音圧が変わって埋もれてしまう場合は、まずシステムで合っているパートを私が確認し、その設定を少しいじることでほかのパートにも同じ混ざり具合が適用されるように調整する必要がある。
>
> **②** ボーカルの下処理（ノイズ除去・音程補正）、音の均し、EQ、コンプ、ボーカルがオケに合うような質感調整など、ディレイで飛ばしたりオートチューン・過度な歪みを必要とする局所的なクリエイティブを要するパート以外は、そのまま適用できるレベルまでもっていけるような一貫したシステムに昇華し、ボタンを押すだけでそこまでもっていくことが理想。オケの音圧が変わったりしても、ボーカルの芯の太さ具合を調整して、すべてのパートにおいて日本語または英語の歌詞単位で違和感がないような距離感の安定度になっている必要がある。
>
> **③** フッと儚く抜けていくパートのリバーブや、オートチューン・ラジオボイスなどの特殊効果を、歌詞単位または秒単位でボーカルに合わせて適用し、本家のミックスのスタイルを可能な限り再現する。
>
> **④** コーラスのメロディーを提案してもらってガイドを作ってもらったり、ハモリの提案をしてもらったり、少しクリエイティブでアイデアが必要になる箇所まで、歌ってみたのディレクターとして手伝ってもらいながら、一緒に歌ってみたの製作を行うことで、よりハイクオリティにする。

### ユーザーの標準手動ワークフロー（設計の原点）

1. リップノイズ・クリック・ブレスなどのノイズ処理
2. ピッチ補正
3. 波形の太さを整えて、オケに負けない太い土台を作る
4. アナライザでオケのスペクトラムを見ながら、ボーカルが馴染むように削ったり増幅したりする
5. コンプや EQ などで距離感・混ざり具合を調整していく
6. レゾナンス抑制系プラグインで滑らかな音にしていく
7. 必要そうであれば歪ませたり汚したりして音を太くする
8. マスタリング

## 3. 次期 R&D 方針（合意済み・継続探索テーマ）

1. **全プロセッサのセクション・時間変化適応（Multi-Section / Time-Varying DSP）**
   基準サビの単一アンカー最適化から脱却し、静かな A メロ・疾走サビ・ブレイクダウン等の音響クラスタごとに EQ・コンプ・サチュレーション・`Soothe2`・リミッターを最適化してフレーズ境界で滑らかにモーフィング／トラック分割する。併せて `BeatNet` / `beat_this` 等による連続テンポ・拍グリッド推定を導入し、テンポ変化曲でもコンプリリース・ディレイ・プリディレイが追従する構造を目指す。
2. **微分可能プロキシ高速探索＋実 VST3 蒸留の二段最適化（仮説）**
   多セクション・多パラメータ探索の計算コストを抑えるため、`dasp-pytorch` / `DiffVox` 系の微分可能 DSP プロキシで GPU 上の大域最適化を行い、最終的に実 VST3 へ蒸留・微調整する構成を検証する。
3. **`muse` を用いた大規模リファレンス DB 構築と自動検品ゲート**
   `muse` AI による大量の歌ってみた音源収集を活かし、44 曲から数百〜数千曲規模へ拡張する。ただし低ビットレート劣化・キー変更や独自アレンジによるオフボ不整合・ジャンル偏りを防ぐため、帯域上限検査・オフボ相互相関アライメント検証・重複排除・ジャンル／声域／MIX 師メタデータ層別化を自動化する。十分な規模に達した段階で、9-NN から条件付き回帰モデルおよび Stage ③ 演出事前分布学習への昇華を狙う。
4. **Studio One 手直し差分からの好み学習（Human-in-the-Loop）**
   自動生成 `.song` とユーザーが Studio One 5 で微調整した `.song` の `.vstpreset` / フェーダー差分を解析し、客観リファレンス目標に対するユーザー固有の審美オフセットを継続学習する。
5. **無補正生ボーカル評価基盤＋`SOFA` 音素アライメント**
   無補正テイクと Melodyne 補正済み正解テイクのペアを用意し、`SOFA` で母音・子音・ブレス境界を特定したうえで「子音アタックを壊さず母音の芯だけをグリッドと音程に乗せる」補正器を定量評価しながら構築する。
6. **ブラインド A/B 比較ハーネス＆Studio One `.envelopex` オートメーション解析**
   ラウドネス正規化済みの代表クリップ（サビ・静寂パート・高歯擦音フレーズ）を複数曲で自動書き出しして回帰劣化を防ぎつつ、Studio One 5 ネイティブのボリューム／センドオートメーション（`.envelopex`）書き出しを解析・実装する。
