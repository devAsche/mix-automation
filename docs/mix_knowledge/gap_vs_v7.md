比べたもの:
- v7 の 2mix チェーン。`src/mix_automation/pipeline.py` と `dsp/vst3_optimizer.py` から調べた（調査メモは `data/processed/mix_knowledge/v7_chain.md` に置いていて、コミットしない）。

## 一致している（変えなくてよい）点

- 着地 -9 LUFS（RTVPdDmWrwo@22:34）。
- 小さいルームの長さ（0.44s）とプリディレイ（10ms）。
- リバーブのダッキング（プレート 0.68+0.32 倍）。
- 1/8 ディレイのダッキング。
- 区間ごとの空間量 `space_env`。
- ハモリの空間がメインより簡素なこと。
- ボーカル追従のライダー群（ルールブックは手動のオートメーション）。

## R2 以降への提案（判断はメインのスレッドで）

1. まず ★★★ の 4 つを試す。手持ちで実現する方法は [plugin_map.md](plugin_map.md) を参照。
   - ダブラーを 2mix に出す
   - コンプの総 GR を 6〜10dB に深くする
   - オケのマルチバンドサイドチェイン
   - 2mix の M/S とグルーを並列にする
2. 空間の数値（プレート 40ms / 1.3s / 3.4kHz、ルーム 2.7kHz / 100Hz、スラップ 150ms）は rules.yaml の範囲を初期値にして、ST-ITO 方式の参照合わせで曲ごとに詰める。
