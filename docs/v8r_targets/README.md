## 2. 引き算（cover − T(inst)）

手順は次のとおり。

- a. ドリフト
  - 50〜250 Hz に絞った相互相関で、8 s 窓を 5 s ごとに取り、遅れの曲線を出した。
  - 幅が 0.1 ms 未満なら一定、直線に乗れば直線、それ以外は区間ごとの曲線で時間を合わせた（窓付き sinc）。
- b. 時間で変わる線形補正
  - STFT（4096 / 1024）の各ビンで、3 s ごとに inst の M/S から cover の M/S への 2×2 伝達関数を最小二乗で推定し、ブロックの間は補間した。
  - さらに、8 帯域の速いゲインを 70 ms ごとに追従させた。リミッターとダッキングを拾うため。
  - 評価は交差検証にした。伝達関数は 0.5 s ごとの交互、ゲインは偶数・奇数ビンで、推定に使っていない側の残差を測っている。
- 残差の定義
  - 声の無い区間の、cover に対するエネルギー比（30 Hz〜16 kHz）。
  - 声の区間は分離した声から決め、後ろに 0.46 s 広げた。
- 使える秒数の定義
  - 声の区間のうち、近くのブロックの残差が −15 dB より深い秒数。

### 手法の検証（v8）

- 声とオケを知っている v8 レンダーでも、残差は −20〜−26 dB にとどまる。固定の伝達関数だけでは −13〜−17 dB。
- v8 のマスターから取り出した声と VocalBus の差は、ゲインを合わせて −8 dB。
  - 理由: マスター段（サチュ・リミッター）が声にもかかるため。
  - 取り出せるのは「マスター後の声」。
- 声−オケ LU は、取り出した声で −1.5、VocalBus で −1.3。ラウドネスの測定にはほぼ影響しない。
- v8 のオケのダッキング（設定は最大 3 dB）は、実測で −2.0 dB（Eva、1–3k）と −3.1 dB（Six、1–3k）として測れた。

### 結論

- **Amo 8 曲は引き算できない。** 正解は BS-RoFormer の分離版。
  - いちばん良い ApocalypseTokyo でも −13.5 dB。
  - 2–8 kHz のコヒーレンスが低い（0.13〜0.84）。cover の中のオケは、配布 inst と別の版か、別の処理を通っている。前回のパイロットと同じ結論。
- **凌さんの曲は 16 本中 8 本で引き算が通った。** Eva 4 本、FallInLove 1 本、LoveAndDestroy 3 本。
  - LoveAndDestroy は、v7 のオフボが 66 s しかなく、その範囲だけが対象。声の無い区間も 6 s しかないので、参考扱い。
- **SixFeetUnder は 4 本とも不可。**
  - コヒーレンスが 0.3 以下で、カバーの中のオケは v7 のオフボと別物。
  - Motoya と Yuunagiki は編集・テンポずれもある（ドリフト 30〜40 ppm、段差 2〜7 回）。

## 5. 判断が要る点

1. **声−オケの目標値。**
   - 同じ曲のプロ（引き算）は、v8 より声が約 4 LU 大きい（+2.6 対 −1.6）。既定値の範囲の上限（+0.5）も超えている。
   - ただし、プロの値はハモリ・コーラス込み、v8 はリードのみ。
   - 案: R4 の探索範囲を −3〜+5 LU に広げ、比べるときはハモリの有無を揃える。
2. **オケのダッキング。**
   - プロの引き算 8 本には、声に合わせた帯域ダッキングがほとんど無い。v8 は 2〜3 dB かけている。
   - 案: 既定値を 1 dB 以下に下げるか、R4 で 0 を含めて探す。解説動画（DuFqH_AWANc）と記事では「1〜2 dB」程度。
3. **Amo の正解は分離版だけ。**
   - 残響の尾と声の大きさが低めに出る。
   - 案: R4 では、Amo は EQ・コンプ・定位の参照に使う。空間と音量の参照は、引き算が通った凌さんの曲の 8 本にする。
4. **SixFeetUnder には引き算の正解が無い。**
   - プロのカバーのオケが、v7 のオフボと違う。この曲の参照は分離版だけになる。
5. **R1 追補（rulebook 5.4）で見つかった食い違い。**
   - リードのコンプの合計 GR: R3 は 8.5 dB、記事は 3〜6 dB。
   - リバーブのダッキングは、もっと深く速い。
   - オートメーションは音節単位。

## レビューでの決定（2026-11-27、クラウド側）

R4（参照合わせ）は、次の前提で進める。

1. **声−オケの目標:** 探索範囲を −3〜+5 LU に広げる。同じ曲のプロ 8 本の中央値は +2.6 LU で、v8 より約 4 LU 大きい。ただしプロの値はハモリ込みなので、比較は「凌のハモリステムが無音で、プロの声の S/M が低い区間」（メインだけの区間）で行う。
2. **オケのダッキング:** 既定値を 0.5 dB に下げ、探索範囲は 0〜3 dB にする。同じ曲のプロは、ほぼダッキングしていない（±0.5 dB）。解説の推奨とは食い違うので、最後は凌の A/B で決める。
3. **参照の使い分け:**
   - Amo 8 曲は分離版しかないので、EQ・コンプ（音色とダイナミクス）の参照だけに使う。
   - 空間と音量の参照は、凌の曲の引き算 8 本（エバ 4、ラブ&デストロイ 3、Fall in Love 1）にする。
4. **シックスフィートアンダー:** 引き算の正解が無い。音色とダイナミクスは分離版に合わせ、空間と音量の範囲は他の 3 曲から借りる（推測にもとづく扱い）。
5. **コンプの合計 GR:** 既定値を 6 dB に下げ、探索範囲は 3〜11 dB にする。量はプロの声のダイナミクス（短時間ラウドネスの幅）に合わせて決める。
6. **声の幅:** プロ −10.7 dB（ハモリ込み）に対して v8 は −15.6 dB。メインだけの区間でも差が残るかを R4 で確かめる。
