# MIX Automation (`mix-automation`)

歌ってみた制作における「上級者クオリティのボーカルMIX」と「高頻度投稿のための圧倒的な時短・汎用化」を両立する専用自動MIXエンジンです。

## 基本思想・設計原則

1. **絶対値ではなく「対オケ相対音響プロファイル（不変量）」の最適化**
   曲ごとに音圧やアレンジ密度が異なっても破綻しないよう、一流MIX師・商業音源の2mixとBS-RoFormer分離音源から抽出した「オケに対するボーカルの帯域別ラウドネス比（マスキングマージン）」「対オケ・クレストファクター比（張り付き感・位置の安定感）」「共鳴ピーク抑制基準」を数理ターゲットとして最適化します。
2. **決定論的DSP・VST3数値最適化エンジン（心臓部）とLLMディレクター（頭脳）の厳格な分離**
   0.1dB・ミリ秒単位の精度が求められる下処理・EQ・コンプ・レゾナンス抑制（目標①・②）はLLMを介さない100%決定論的な信号処理＋数値最適化エンジンが担い、歌詞の文脈に応じた空間演出（目標③）やハモリ・コーラスのアレンジ提案（目標④）、抽象的な要望の数値目標への翻訳にのみLLMを連携させます。
3. **実機所有の最高峰VST3プラグイン資産の直接駆動**
   `spotify/pedalboard` を介してローカル環境の **iZotope RX 10**（Mouth De-click / Breath Control / Voice De-noise / De-ess）、**UAD Teletronix LA-2A / Pultec EQP-1A**、**Oeksound Soothe2**、**Rev PLATE-140 / PhoenixVerb** 等を直接制御・最適化します。
4. **Studio One 5.5 ネイティブ連携（`.song` テンプレート注入 ＆ `.vstpreset` 出力）**
   処理完了後、Studio One 5 でそのまま開いてプラグインの数値を微調整できるプロジェクトファイル（`.song`）および標準 `.vstpreset`、さらに1パートの手直しを全パートへ自動換算・波及させる「アンカー伝播機構」を提供します。

詳細な設計は [docs/ARCHITECTURE.md](docs/ARCHITECTURE.md) を参照してください。
